# Contributing to StreamBoard

Thanks for helping! Bug reports, ideas and pull requests are welcome.

## Before you start

- For a bug, open an [issue](https://github.com/BKNadir/streamboard/issues) with the plugin logs attached (see the [user guide](docs/en.md#troubleshooting)).
- For a new feature, open an issue first so we can agree on the idea before you spend time on it.

## Development

```bash
npm install
npm run build
npx streamdeck link com.bknadir.streamboard.sdPlugin
```

`npm run typecheck` must pass, and the CI must be green on your pull request.
